# 낱말 노트

영어 단어를 카드와 퀴즈로 익히는 학습 페이지입니다. 빌드나 설치 없이 `index.html` 하나만으로 동작합니다.

## 실행

`index.html`을 더블클릭해 브라우저에서 엽니다.

## 학습 방법

단어는 40개이며, 일상·여행·비즈니스·감정·학술로 나뉩니다. 각 단어에는 뜻, 품사, 난이도, 예문과 해석이 있습니다.

- **카드:** 단어를 누르면 뜻과 예문이 나옵니다. `알아요`와 `아직 몰라요`로 표시하고, 발음을 들을 수 있습니다.
- **퀴즈:** 선택한 범위에서 최대 10문제를 냅니다. 뜻을 보고 단어를 고르거나, 단어를 보고 뜻을 고릅니다. 틀린 단어만 다시 카드로 볼 수 있습니다.
- **단어장:** 영어, 뜻, 예문으로 찾고, 주제와 학습 상태로 걸러 볼 수 있습니다.
- **오늘의 단어:** 날짜마다 단어 하나가 바뀝니다. `뜻 보기`로 뜻을 확인하고, `카드로 보기`로 그 단어의 카드로 이동합니다.

`카드·퀴즈는 모르는 단어만`을 켜면 아직 모르는 단어만 카드와 퀴즈에 나옵니다. 단어장은 이 설정과 별도로 전체를 보여 줍니다.

## 키보드

카드 화면에서 입력창에 커서가 없을 때 사용할 수 있습니다.

| 키 | 동작 |
| --- | --- |
| `Space`, `Enter` | 뜻 보기 / 뜻 닫기 |
| `←` | 아직 몰라요 |
| `→` | 알아요 |
| `P` | 발음 듣기 |

퀴즈에서는 `1`–`4`로 보기를 고르고, 답을 확인한 뒤 `Enter`로 다음 문제로 넘어갑니다.

## 학습 기록

아는 단어와 퀴즈 최고 점수는 이 브라우저의 `localStorage`에만 저장됩니다. 다른 브라우저나 다른 컴퓨터와는 공유되지 않습니다. 페이지 아래의 `기록 지우기`로 기록을 삭제할 수 있습니다.

발음은 브라우저의 음성 읽기를 사용합니다. 브라우저에 따라 목소리가 다르거나, 음성 읽기를 지원하지 않을 수 있습니다.
